# Changelog

## 1.0.0 — 2026-11-14

### Added
- **Tokens**: PPTokens (colours light/dark, palette, spacing, radii, type), PPScales (line heights, control sizes, focus ring, scrim)
- **Icons**: 181 Lucide icons as PPIconName + PPIcon view
- **Fonts**: Geist and Geist Mono fonts with PPFonts.register()
- **Theme**: PPTheme environment and .pigeonpostTheme()
- **Components**: PPButton, PPIconButton, PPTextField, PPOTPField, PPToggleRow, PPAvatar, PPBadge, PPTag, PPCard, PPListRow, PPSectionHeader, PPEmptyState, PPBanner, PPToast, PPProgress, PPMeter, PPSkeleton, PPMessageBubble, PPTicks, PPComposer, PPThreadRow, PPConversationHeader, PPAddressChip, PPTypingIndicator, PPCallControls, PPIncomingCallView, PPPricingCard, PPCreditBalance, PPCreditChip, PPListingCard, PPNestCard, PPTabBar
- **Tests**: 10 XCTest unit tests (token values, bubble corners, initials and tone hash, icon paths, font registration)
