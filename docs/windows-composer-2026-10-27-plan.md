No automatic replay and no silently replacing a pending intent.

Add reply/edit mode, cancel restoration and capability/expiry gates, plus accessible pending-delivery review controls aligned with the existing desktop design. Keep rendered view identity distinct from a caller-bound action.
5. Run focused behavioral tests, the combined Core/MLS suite and a clean Release build; prove committed-response-loss restart recovery against a real loopback postbox. Extend actual WinUI tests for composer/recovery, account/context changes and DPAPI, then qualify exact-head native packages/CI before merge.
