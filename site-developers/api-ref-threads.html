Conversations within a mailbox.

MethodPathDoes
GET/v1/archivePeers whose conversations this mailbox has archived
PUT/v1/archiveArchive or restore a peer's conversation (local view only)
GET/v1/threadsThe acting mailbox's conversations, most recent first
POST/v1/threadsOpen a named thread with a peer (created on both sides)
PATCH/v1/threads/{id}Rename or archive one thread in this mailbox only, or set its disappearing timer on both sides
DELETE/v1/threads/{id}Delete one thread and its mail in this mailbox only (irreversible)

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/archive#

Peers whose conversations this mailbox has archived

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 Archived peers.

{
  "archived": []
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/archive" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

PUT /v1/archive#

Archive or restore a peer's conversation (local view only)

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "peer": "string",
  "archived": true,
  "identity": "string"
}

Responses

200 Done.

{
  "ok": true
}

Errors

HTTPMeaning
400invalid_peer, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X PUT "https://postbox.pigeonpost.dev/v1/archive" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"peer": "string", "archived": true, "identity": "string"}'

GET /v1/threads#

The acting mailbox's conversations, most recent first

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
peerquerystringAddress or handle; an unknown peer yields an empty list.
include_archivedqueryboolean
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 Threads.

{
  "threads": [
    {
      "thread_id": "string",
      "peer": "string",
      "title": "string",
      "is_default": false,
      "created_at": 0,
      "last_at": 0,
      "archived": false
    }
  ]
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/threads" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/threads#

Open a named thread with a peer (created on both sides)

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "peer": "string",
  "title": "string",
  "identity": "string"
}

Responses

201 Opened.

{
  "thread_id": "string"
}

Errors

HTTPMeaning
400bad_thread_title, unknown_recipient, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/threads" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"peer": "string", "title": "string", "identity": "string"}'

PATCH /v1/threads/{id}#

Rename or archive one thread in this mailbox only, or set its disappearing timer on both sides

Credentials: apiKey, capToken, memberToken

ephemeral_secs (null, 300, 3600, 28800, 86400, 604800, 2419200) needs the disappearing flag; it applies to both sides of the thread and only to new messages (SDS §17).

Parameters

NameInTypeRequiredDescription
idpathstringyes

Request body

application/json

{
  "title": "string",
  "archived": false,
  "ephemeral_secs": 0,
  "identity": "string"
}

Responses

200 Updated.

{
  "ok": true
}

Errors

HTTPMeaning
400bad_thread_title, unknown_thread, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X PATCH "https://postbox.pigeonpost.dev/v1/threads/$ID" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "string", "archived": false, "ephemeral_secs": 0, "identity": "string"}'
