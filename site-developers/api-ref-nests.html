Nests (hosted agents) — packages, purchases, slots and paid setups (feature nests, docs/nests/).

MethodPathDoes
GET/v1/nest-packagesThe Nest package catalog and this account's store binding tokens (feature nests)
GET/v1/nestsThis account's Nest allowance, Nests and paid setups (feature nests)
POST/v1/nestsCreate a Nest in a free slot of the account's package (a person only)
POST/v1/nests/enrollA Nest sandbox redeems its one-time enrollment code (no credential)
POST/v1/nest-purchases/intentsRecord a purchase intent before a store sheet or web checkout (a person only)
POST/v1/nest-purchases/appleClaim or restore an App Store Nest subscription (a person only)
POST/v1/nest-purchases/googleClaim or restore a Google Play Nest subscription (a person only)
POST/v1/nest-setups/{id}/retryRetry a paid-but-unprovisioned Nest setup now (a person only)

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/nest-packages#

The Nest package catalog and this account's store binding tokens (feature nests)

Credentials: apiKey, memberToken

Packages, which purchase rails this server accepts, and the opaque values a native purchase must carry: StoreKit appAccountToken and Google Play obfuscatedAccountId. Prices come from the store (native) or the billing bridge (web), never from here. See docs/nests/phase-b.md.

Responses

200 The catalog.

{
  "catalog_version": "string",
  "packages": [
    {
      "code": "string",
      "name": "string",
      "rank": 0,
      "slots": 0,
      "storage_bytes": 0,
      "active_hours": 0,
      "input_tokens": 0,
      "output_tokens": 0,
      "model": "managed",
      "sellable": false,
      "apple_product_id": "string",
      "google_product_id": "string",
      "google_base_plan_id": "string",
      "web_plan": "string"
    }
  ],
  "rails": {
    "apple": false,
    "google": false,
    "web": false
  },
  "app_account_token": "string",
  "google_account_id": "string"
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403feature_disabled or credential_not_accepted (a mailbox token or connector)

Example

curl -sS "https://postbox.pigeonpost.dev/v1/nest-packages" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/nests#

Create a Nest in a free slot of the account's package (a person only)

Credentials: memberToken

Request body

application/json

{
  "label": "string"
}

Responses

201 Created; the sandbox enrolls within seconds.

{
  "nest_id": "string",
  "address": "string",
  "state": "string"
}

Errors

HTTPMeaning
400bad_label
401unauthorized — missing, unknown, revoked or invalid credential.
402no_nest_package: buy a Nest package first
403feature_disabled or human_required
409nest_slots_full
502nestd_failed: the worker host did not provision; nothing is charged again and the slot is released

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/nests" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"label": "string"}'

POST /v1/nests/enroll#

A Nest sandbox redeems its one-time enrollment code (no credential)

Credentials: none

The sandbox signs pigeonpost-nest-enroll-v1\0 + code with a fresh Ed25519 device key. Redemption rotates the Nest mailbox's capability token and returns it to the sandbox alone. Every refusal is the same enrollment_invalid.

Request body

application/json

{
  "code": "string",
  "device_public_key": "string",
  "signature": "string"
}

Responses

200 Enrolled.

{
  "nest_id": "string",
  "address": "string",
  "capability_token": "string"
}

Errors

HTTPMeaning
400enrollment_invalid
429enrollment_rate_limited

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/nests/enroll" \
  -H "Content-Type: application/json" \
  -d '{"code": "string", "device_public_key": "string", "signature": "string"}'

POST /v1/nest-purchases/intents#

Record a purchase intent before a store sheet or web checkout (a person only)

Credentials: memberToken

Refuses a purchase that would fund the account twice: a live package on another rail (nest_package_active) or the same package on this rail (nest_package_owned). Upgrades on the funding rail are allowed. The intent grants nothing; only the verified purchase does.

Request body

application/json

{
  "package": "nest.ai.starter.monthly",
  "rail": "apple"
}

Responses

200 The intent and the product to buy.

{
  "intent_id": "string",
  "expires_at": 0,
  "package": "string",
  "rail": "string",
  "catalog_version": "string",
  "apple_product_id": "string",
  "google_product_id": "string",
  "google_base_plan_id": "string",
  "web_plan": "string",
  "app_account_token": "string",
  "google_account_id": "string"
}

Errors

HTTPMeaning
400unknown_package or unknown_rail
401unauthorized — missing, unknown, revoked or invalid credential.
403feature_disabled or human_required
409nest_package_active or nest_package_owned
429rate_limited
503billing_unavailable: that store is not configured

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/nest-purchases/intents" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"package": "nest.ai.starter.monthly", "rail": "apple"}'
