POST /v1/nests/{nest}/files#

Upload one file to the Nest (a person only, at most 25 MiB)

Credentials: memberToken

Raw bytes in the body; the display name, percent-encoded UTF-8, in x-file-name. The Nests host quarantines the file and parses it (PDF, DOCX, TXT/MD, CSV, XLSX, ZIP) in a separate sandbox with no network. Only verified text reaches the Nest. Archive entries with unsafe paths, archive bombs and nested archives are skipped and listed in warnings.

POST /v1/nests/{nest}/approvals/{approval}/{decision}#

Approve or reject exactly the call that was shown (a person only)

Credentials: memberToken

The body echoes the args_hash the person saw. A changed call (approval_changed), a replaced, decided or expired card (approval_closed) and a recipient outside the destination policy (recipient_not_allowed: only the owner's own mailboxes and contacts they allowed) are refused. An approved card is carried out once by the postbox, never by the Nest.

Parameters

NameInTypeRequiredDescription
nestpathstringyes
approvalpathstringyes
decisionpathstringyesOne of approve, reject.

Request body

application/json

{
  "args_hash": "string"
}

Responses

200 Decided (and, for approve, carried out).

{
  "approval_id": "string",
  "status": "approved",
  "result": "string"
}

POST /v1/nests/enroll#

A Nest sandbox redeems its one-time enrollment code (no credential)

Credentials: none

The sandbox signs pigeonpost-nest-enroll-v1\0 + code with a fresh Ed25519 device key. Redemption rotates the Nest mailbox's capability token and returns it to the sandbox alone. Every refusal is the same enrollment_invalid.

Request body

application/json

{
  "code": "string",
  "device_public_key": "string",
  "signature": "string"
}

Responses

POST /v1/nest-purchases/intents#

Record a purchase intent before a store sheet or web checkout (a person only)

Credentials: memberToken

Refuses a purchase that would fund the account twice: a live package on another rail (nest_package_active) or the same package on this rail (nest_package_owned). Upgrades on the funding rail are allowed. The intent grants nothing; only the verified purchase does.

application/json

{
  "package": "nest.ai.starter.monthly",
  "rail": "apple"
}

  "web_plan": "string",
  "app_account_token": "string",
  "google_account_id": "string"
}
