# Pigeonpost Design Kit — vendored CSS kit 1.0.0

Copied byte for byte from the design kit's `kits/web/css/dist/` (pigeonpost-design-kit commit 0b790ef,
https://design.pigeonpost.dev). Do not edit these files; update them by copying a newer kit release.

- `pp-ui.min.css` — tokens, base type roles and every `pp-*` component (fonts load from `fonts/`)
- `fonts/` — Geist, Geist Italic and Geist Mono variable woff2 (SIL OFL 1.1, see `LICENSES/`)
- `icons.svg` — the kit's Lucide icon sprite (ISC, see `LICENSES/`)
- `brand/` — logo symbol lockups from the kit's `assets/brand/`

This site's own layer on top is `/docs.css`.
