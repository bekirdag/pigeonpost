GET /v1/profile/avatar#

The acting mailbox's own picture (feature avatars)

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 The picture, or null.

{
  "avatar": {
    "id": "string",
    "version": 0,
    "visibility": "everyone",
    "hash": "string",
    "urls": {
      "64": "string",
      "128": "string",
      "256": "string",
      "512": "string",
      "jpeg": "string"
    },
    "created_at": 0
  }
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404feature_disabled (flag off for this account), not_found

Example

curl -sS "https://postbox.pigeonpost.dev/v1/profile/avatar" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

PUT /v1/profile/avatar#

Set the picture from a raw image

Credentials: apiKey, capToken, memberToken

The body is the image itself (JPEG, PNG or WebP, at most 10 MB; convert HEIC on the device). The server decodes it in an isolated worker, strips every piece of metadata, crops a square and stores WebP at 64/128/256/512 px plus a 256 px JPEG. Five changes per mailbox per day.

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.
cropquerystringx,y,w,h in source pixels after EXIF orientation; omitted = centre square.
visibilityquerystringOne of everyone, known, nobody.
allquerystringApply to every mailbox of the caller's account. One of 1, true.

Request body

image/*

Responses

200 Stored. With all, avatars lists each mailbox and rate_limited those over the limit.

{
  "avatar": {
    "id": "string",
    "version": 0,
    "visibility": "everyone",
    "hash": "string",
    "urls": {
      "64": "string",
      "128": "string",
      "256": "string",
      "512": "string",
      "jpeg": "string"
    },
    "created_at": 0
  },
  "avatars": [
    {
      "address": "string",
      "avatar": {
        "id": "string",
        "version": 0,
        "visibility": "everyone",
        "hash": "string",
        "urls": {
          "64": null,
          "128": null,
          "256": null,
          "512": null,
          "jpeg": null
        },
        "created_at": 0
      }
    }
  ],
  "rate_limited": [
    "string"
  ]
}

Errors

HTTPMeaning
400bad_request (crop or visibility)
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404feature_disabled (flag off for this account), not_found
413too_large
415unsupported_image
422bad_image
429avatar_rate_limited
503avatars_unavailable

Example

curl -sS -X PUT "https://postbox.pigeonpost.dev/v1/profile/avatar" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: image/*" \
  --data-binary @file

PATCH /v1/profile/avatar#

Change who may see the picture (bumps its version; old URLs stop working)

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "visibility": "everyone",
  "identity": "string"
}

Responses

200 Changed.

{
  "avatar": {
    "id": "string",
    "version": 0,
    "visibility": "everyone",
    "hash": "string",
    "urls": {
      "64": "string",
      "128": "string",
      "256": "string",
      "512": "string",
      "jpeg": "string"
    },
    "created_at": 0
  }
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404feature_disabled (flag off for this account), not_found

Example

curl -sS -X PATCH "https://postbox.pigeonpost.dev/v1/profile/avatar" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"visibility": "everyone", "identity": "string"}'

GET /v1/avatar-blobs/{id}/{version}/{file}#

Picture bytes, authorized on every request

Credentials: apiKey, capToken, memberToken (optional)

everyone pictures answer without credentials with Cache-Control: public, max-age=31536000, immutable; others need the caller's credential and answer private, max-age=300.

Parameters

NameInTypeRequiredDescription
idpathstringyes
versionpathintegeryes
filepathstringyesOne of 64.webp, 128.webp, 256.webp, 512.webp, 256.jpg.

Responses

200 The image.

image/webp, image/jpeg

Errors

HTTPMeaning
404not_found

Example

curl -sS "https://postbox.pigeonpost.dev/v1/avatar-blobs/$ID/$VERSION/$FILE" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"
