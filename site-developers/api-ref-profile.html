PUT /v1/profile/avatar#

Set the picture from a raw image

Credentials: apiKey, capToken, memberToken

The body is the image itself (JPEG, PNG or WebP, at most 10 MB; convert HEIC on the device). The server decodes it in an isolated worker, strips every piece of metadata, crops a square and stores WebP at 64/128/256/512 px plus a 256 px JPEG. Five changes per mailbox per day.

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.
cropquerystringx,y,w,h in source pixels after EXIF orientation; omitted = centre square.
visibilityquerystringOne of everyone, known, nobody.
allquerystringApply to every mailbox of the caller's account. One of 1, true.

Request body

image/*

Responses

200 Stored. With all, avatars lists each mailbox and rate_limited those over the limit.

Errors

HTTPMeaning
400bad_request (crop or visibility)
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404feature_disabled (flag off for this account), not_found
413too_large
415unsupported_image
422bad_image
429avatar_rate_limited
503avatars_unavailable

PUT /v1/profile/name#

Set the acting mailbox's self-chosen display name

Credentials: apiKey, capToken, memberToken

Free for everyone and not a verified identity: clients show it as ~Name and keep the address or handle one tap away (docs/contacts-and-phone.md §6). 1–40 characters; no /, @, control, format, bidi or invisible characters; reserved words and anything containing "pigeonpost" are refused. Ten changes per mailbox per day. A connector acting for the member may not set it.

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Request body

application/json

Responses

200 The stored name.

Errors

HTTPMeaning
400invalid_name, bad_request
401unauthorized — missing, unknown, revoked or invalid credential.
403credential_not_accepted (a connector), wrong_identity
404feature_disabled
429rate_limited (with Retry-After)

Example

GET /v1/profiles#

Display names of up to 100 addresses, as the caller may see them

Credentials: apiKey, capToken, memberToken

Each requested address maps to {address, handle, display_name} or null (no such mailbox). display_name is null when there is none, it is not visible to the caller (same rules as profile pictures), or the owner's account does not have display_names. A credential is required.

Parameters

NameInTypeRequiredDescription
addressesquerystringyesComma-separated addresses or handles (at most 100).

Responses

200 Names by requested address.

Errors

HTTPMeaning
400bad_request (more than 100 addresses)
401unauthorized — missing, unknown, revoked or invalid credential.
