POST /v1/attachments#

Upload a file for a later send

Credentials: apiKey, capToken, memberToken

The raw bytes are the request body; metadata travels in headers. The upload stays unclaimed (and counts against the mailbox quota) until a send names it. 404 not_found when this postbox has attachments disabled.

Parameters

NameInTypeRequiredDescription
x-pigeonpost-identityheaderstringWhich of the account's mailboxes to act as.
x-pigeonpost-filenameheaderstring
x-pigeonpost-media-typeheaderstringNarrowed server-side to a safe set.

Request body

application/octet-stream

Responses

201 Stored.

Errors

HTTPMeaning
400empty_attachment, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404not_found
409mailbox_full
413attachment_too_large
500store_error, storage_error
507storage_full

Example

GET /v1/attachments/{id}#

Download an attachment held by the acting mailbox

Credentials: apiKey, capToken, memberToken

Always served with Content-Disposition - attachment. Not-yours and not-there both answer 404 not_found.

Parameters

NameInTypeRequiredDescription
idpathstringyes
x-pigeonpost-identityheaderstring

Responses

200 The bytes, with the stored media type.

application/octet-stream

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404not_found
500store_error (or another server-side code such as vault_error).
