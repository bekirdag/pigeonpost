Health, onboarding and discovery.

MethodPathDoes
GET/Self-serve onboarding page
GET/healthLiveness check
GET/review-sign-inApp-review sign-in demonstration page
POST/review-sign-inGenerate a fresh device-authorization QR code
GET/v1/capabilitiesWhat this server and this credential can do

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /#

Self-serve onboarding page

Credentials: none

Static HTML page that solves the proof-of-work in the browser, mints an inbox and shows an MCP connector config.

Responses

200 HTML page.

text/html

Example

curl -sS "https://postbox.pigeonpost.dev/"

GET /health#

Liveness check

Credentials: none

Responses

200 Service is up.

{
  "status": "ok",
  "service": "pigeonpost-postbox",
  "version": "string",
  "stage": "string"
}

Example

curl -sS "https://postbox.pigeonpost.dev/health"

GET /review-sign-in#

App-review sign-in demonstration page

Credentials: none

HTML page that lets an app reviewer generate a real device-authorization QR code. Never returns user tokens.

Responses

200 HTML page.

text/html

Example

curl -sS "https://postbox.pigeonpost.dev/review-sign-in"

POST /review-sign-in#

Generate a fresh device-authorization QR code

Credentials: none

Globally rate limited to one code per 15 seconds. Responses are HTML.

Responses

200 HTML page with a QR code and confirmation code.

text/html

Errors

HTTPMeaning
429Another code was generated less than 15 seconds ago (HTML).
502The sign-in service is unavailable (HTML).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/review-sign-in"

GET /v1/capabilities#

What this server and this credential can do

Credentials: apiKey, capToken, memberToken

Responses

200 Capabilities for the caller.

{
  "api_version": "1.1",
  "server_version": "string",
  "features": [
    "string"
  ],
  "event_types": [
    "string"
  ],
  "credential": {
    "kind": "member",
    "human": false,
    "step_up": {
      "configured": false,
      "satisfied": false,
      "acr_values": [
        "string"
      ],
      "max_age": 0
    }
  }
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.

Example

curl -sS "https://postbox.pigeonpost.dev/v1/capabilities" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"
