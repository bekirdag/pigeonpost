Member API reference

Every endpoint of the postbox member API (https://postbox.pigeonpost.dev), generated from openapi/pigeonpost.v1.yaml, one page per area. The HTTP API page explains credentials and the common flows; this reference lists every operation with its parameters, bodies and responses. The internal service API (separate listener, service tokens) is not listed here.

Downloads: OpenAPI (JSON), Postman collection, Bruno collection. Both collections use the variables {{baseUrl}} and {{token}}.

POST/v1/calendar/events/{id}/cancelCancel an event, one occurrence or the rest of a series
POST/v1/calendar/events/{id}/attendeesAdd or remove attendees (organizer)

PUT/v1/calendar/events/{id}/remindersThe caller's own reminders for an event
PUT/v1/calendar/events/{id}/placementMove an invitation to another of the caller's calendars

POST/v1/calendar/feeds/{calendar_id}Turn a secret feed on (new link, shown once) or off
GET/v1/calendar/feed/{secret}The subscribable feed ({secret}.ics; the secret is the grant)

POST/v1/calendar/guest/previewLimited preview of one's invitation

POST/v1/calendar/guest/verify/completeConfirm the code and get a device-bound guest session
POST/v1/calendar/guest/recoverAsk for a code for a live invitation (always the same answer)
