Stream audit logs to your SIEM

GET /audit returns the org audit log oldest first, so a collector can read it forward and never miss or repeat an entry. It needs a key with audit:read, created by someone with the security permission.

Every entry is {id, at, actor_kind, actor, action, target, details}. Details are sanitized: no tokens, contact addresses or message content. Every Enterprise API request is itself an entry (api_key.use, with the key id as actor), so the log also records what your automation did.

The loop#

  1. 1. On first run, start from a time: ?since=2026-10-27T00:00:00Z.
  2. 2. Follow next_cursor page by page, forwarding entries, and store the cursor after each page so a restart resumes where it stopped.
  3. 3. On the last page next_cursor is null. Remember the last entry's at and id, wait a little, and ask again with since set to that at, skipping the entries you have already sent (since includes entries at that exact second).
  4. 4. Filter with ?action= (a prefix, such as member. or api_key.) if your SIEM only wants some.
import json, os, time, urllib.error, urllib.parse, urllib.request

BASE = "https://postbox.pigeonpost.dev/org/v1/audit"
KEY = os.environ["PIGEONPOST_ORG_KEY"]
STATE = "pigeonpost-audit.state.json"


def load():
    try:
        with open(STATE) as f:
            return json.load(f)
    except FileNotFoundError:
        return {"cursor": None, "since": "2026-10-27T00:00:00Z", "seen": []}


def save(state):
    tmp = STATE + ".tmp"
    with open(tmp, "w") as f:
        json.dump(state, f)
    os.replace(tmp, STATE)


def fetch(params):
    req = urllib.request.Request(BASE + "?" + urllib.parse.urlencode(params),
                                 headers={"Authorization": "Bearer " + KEY})
    with urllib.request.urlopen(req, timeout=30) as resp:
        return json.load(resp)


def forward(entry):
    print(json.dumps(entry))  # replace with your SIEM's ingestion call


state = load()
while True:
    params = {"limit": 200}
    if state["cursor"]:
        params["cursor"] = state["cursor"]
    else:
        params["since"] = state["since"]
    try:
        page = fetch(params)
    except urllib.error.HTTPError as e:
        time.sleep(int(e.headers.get("Retry-After", "30")))
        continue
    for entry in page["data"]:
        if entry["id"] in state["seen"]:
            continue
        forward(entry)
        if entry["at"] != state["since"]:
            state["since"], state["seen"] = entry["at"], []
        state["seen"].append(entry["id"])
    state["cursor"] = page["next_cursor"]
    save(state)
    if page["next_cursor"] is None:
        time.sleep(60)

Forward before you save, so a crash between the two re-sends a page rather than losing one; your SIEM can deduplicate on id.

Limits#

A full page every second is well inside the key's 600 requests a minute; when the log is quiet the loop makes one request a minute. On 429 rate_limited wait Retry-After seconds. A cursor that was altered or comes from a different list is 400 invalid_cursor: drop it and resume from since.

To be told about specific events as they happen instead of polling, use webhooks. They carry ids and handles only and complement the audit log rather than replace it.
