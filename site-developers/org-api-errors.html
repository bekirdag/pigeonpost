Enterprise API errors

Every refusal is {"error": {"code", "message", "doc_url"}}. The code is stable: branch on it, never on message. doc_url points at the entry for its code on this page.

not_org_mailbox#

HTTP 400

The handle or address given is not an active member or agent mailbox of this organization.

Returned by: POST /rules/evaluate, POST /rooms, POST /rooms/{room}/members.

unknown_recipient#

HTTP 400

No mailbox is hosted at the address given to the rule dry run.

Returned by: POST /rules/evaluate.

never_auto_verb#

HTTP 400

The rule names an action that always needs a person to approve it (git_push, deploy, read_credentials, spend, delete_files, run_shell).

Returned by: POST /rules, PATCH /rules/{rule}.

invalid_recipient#

HTTP 400

to is not a Pigeonpost address or handle.

Returned by: POST /messages.

recipient_unresolved#

HTTP 404

No mailbox answers at to.

Returned by: POST /messages.

invite_pending#

HTTP 409

The member has not accepted their invitation yet; remove the member to withdraw it.

Returned by: POST /members/{member}/suspend, POST /members/{member}/reactivate.

send_as_unavailable#

HTTP 409

The agent this key sends as is not an active agent of the organization.

Returned by: POST /messages.

recipient_inbox_full#

HTTP 409

The recipient's mailbox is over its storage quota.

Returned by: POST /messages.

stranger_rate_limited#

HTTP 429

The recipient is receiving too many messages from senders it does not know; retry later.

Returned by: POST /messages.

bad_request#

HTTP 400

The body or a parameter is malformed: not JSON, a wrong type, an unknown enum value, or a field out of range. The message names the field.

Returned by: POST /members, PATCH /members/{member}, POST /agents, POST /rules, PATCH /rules/{rule}, POST /rules/evaluate, POST /rooms, PATCH /rooms/{room}, POST /rooms/{room}/members, POST /webhooks, POST /messages.

invalid_handle#

HTTP 400

A handle is not valid for this org: wrong namespace, bad characters, reserved, or too long. Org handles look like /acme/john; on input the bare name john is accepted too.

Returned by: POST /members, POST /agents, POST /rooms, POST /rooms/{room}/members.

invalid_contact#

HTTP 400

The invitation contact address is not a valid address.

Returned by: POST /members.

invalid_rule#

HTTP 400

A rule pattern or field is malformed: owners outside the org namespace, a pattern with more than one wildcard, a priority outside 1..1000, and so on.

Returned by: POST /rules, PATCH /rules/{rule}.

invalid_cursor#

HTTP 400

The cursor was not produced by this list, or was altered. Pass back next_cursor exactly as received.

Returned by: GET /members, GET /agents, GET /agents/{agent}/delegations, GET /agents/{agent}/enrollments, GET /rules, GET /rooms, GET /audit, GET /webhooks, GET /webhooks/{webhook}/deliveries.

invalid_webhook_url#

HTTP 400

The webhook URL is refused: it must be https:// on port 443 or 8443, without credentials or fragment, at most 2,048 characters, and every address its host resolves to must be public.

Returned by: POST /webhooks.

unauthorized#

HTTP 401

No key, an unknown key, a revoked key or an expired key. One answer for all four, so a caller cannot probe which.

Any operation can return it.

ip_not_allowed#

HTTP 403

The request came from an address outside the key's IP allowlist.

Any operation can return it.

insufficient_scope#

HTTP 403

The key does not hold the scope this route needs. The route's scope is listed in the reference.

Any operation can return it.

forbidden#

HTTP 403

The person who created the key no longer has the authority for this action (demoted or removed), or the target is out of a key's reach: the owner, or a member holding an admin role.

Any operation can return it.

human_required#

HTTP 403

Only a person can do this: granting roles, raising trust with a rule, issuing enrollment codes or device credentials, deleting a person's restriction, and every step-up action.

Returned by: POST /rules, PATCH /rules/{rule}, DELETE /rules/{rule}.

recipient_not_in_org#

HTTP 403

POST /messages: the recipient is not a live mailbox of this org. API messages only go to the org's own members and agents.

Returned by: POST /messages.

not_admitted#

HTTP 403

POST /messages: the recipient's blocks, org rules or inbox policy do not admit messages from the key's send_as mailbox.

Returned by: POST /messages.

not_found#

HTTP 404

No such member, agent, rule, room, webhook or enrollment in this org.

Returned by: GET /members/{member}, PATCH /members/{member}, DELETE /members/{member}, POST /members/{member}/suspend, POST /members/{member}/reactivate, POST /members/{member}/resend-invite, GET /agents/{agent}, DELETE /agents/{agent}, POST /agents/{agent}/disconnect, GET /agents/{agent}/delegations, GET /agents/{agent}/enrollments, DELETE /agents/{agent}/enrollments/{enrollment}, PATCH /rules/{rule}, DELETE /rules/{rule}, POST /rooms, PATCH /rooms/{room}, DELETE /rooms/{room}, POST /rooms/{room}/members, DELETE /webhooks/{webhook}, POST /webhooks/{webhook}/rotate, GET /webhooks/{webhook}/deliveries.

feature_disabled#

HTTP 404

The Enterprise API is not enabled for this org (org_api feature flag).

Any operation can return it.

seat_limit#

HTTP 409

Every seat is in use (owner, active, suspended and invited members all count). Buy seats or remove someone first.

Returned by: POST /members, POST /members/{member}/resend-invite.

agent_limit#

HTTP 409

The org has as many agents as it may (10 per seat).

Returned by: POST /agents.

handle_taken#

HTTP 409

The handle already belongs to a member, an agent, or is held for a successor.

Returned by: POST /members, POST /agents.

already_invited#

HTTP 409

This contact address already has a live invitation or membership in the org.

Returned by: POST /members, POST /rooms/{room}/members.

domain_not_verified#

HTTP 409

The org only invites addresses on its verified domains (invite_domains_only), and this one is not.

Returned by: POST /members.

org_read_only#

HTTP 409

The org is read-only after a lapsed payment: reads work, writes do not.

Returned by: POST /members, PATCH /members/{member}, DELETE /members/{member}, POST /members/{member}/suspend, POST /members/{member}/reactivate, POST /members/{member}/resend-invite, POST /agents, DELETE /agents/{agent}, POST /agents/{agent}/disconnect, DELETE /agents/{agent}/enrollments/{enrollment}, POST /rules, PATCH /rules/{rule}, DELETE /rules/{rule}, POST /rooms, PATCH /rooms/{room}, DELETE /rooms/{room}, POST /rooms/{room}/members, POST /webhooks, DELETE /webhooks/{webhook}, POST /webhooks/{webhook}/rotate, POST /messages.

org_inactive#

HTTP 409

The org is not live (pending, unprovisioned or suspended).

Any operation can return it.

idempotency_conflict#

HTTP 409

This Idempotency-Key was already used on this route with a different request (method, path or body).

Returned by: DELETE /key, POST /members, PATCH /members/{member}, DELETE /members/{member}, POST /members/{member}/suspend, POST /members/{member}/reactivate, POST /members/{member}/resend-invite, POST /agents, DELETE /agents/{agent}, POST /agents/{agent}/disconnect, DELETE /agents/{agent}/enrollments/{enrollment}, POST /rules, PATCH /rules/{rule}, DELETE /rules/{rule}, POST /rules/evaluate, POST /rooms, PATCH /rooms/{room}, DELETE /rooms/{room}, POST /rooms/{room}/members, POST /webhooks, DELETE /webhooks/{webhook}, POST /webhooks/{webhook}/rotate, POST /messages.

room_encrypted#

HTTP 409

POST /messages targeted a room or group. Rooms are end-to-end encrypted; post with an enrolled agent instead.

Returned by: POST /messages.

invite_used#

HTTP 409

The invitation or enrollment code was already accepted, redeemed or revoked, so it cannot be resent or revoked again.

Returned by: POST /members/{member}/resend-invite, DELETE /agents/{agent}/enrollments/{enrollment}.

webhook_limit#

HTTP 409

The org already has 10 webhooks.

Returned by: POST /webhooks.

too_many_rules#

HTTP 409

The org already has as many rules as it may.

Returned by: POST /rules.

payload_too_large#

HTTP 413

The message body is over 64 KB.

Returned by: POST /messages.

rate_limited#

HTTP 429

Over the key's rate limit (600 requests a minute, of which 60 writes). Wait for Retry-After seconds.

Any operation can return it.

store_error#

HTTP 500

The server could not complete the request. Safe to retry with the same Idempotency-Key.

Any operation can return it.
