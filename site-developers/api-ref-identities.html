Mailboxes (identities) and their names.

MethodPathDoes

POST/v1/identitiesCreate a mailbox

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/identities#

List the account's mailboxes

Credentials: apiKey, memberToken

Responses

200 Mailboxes.

{
  "identities": [
    {
      "address": "string",
      "label": "string",
      "handle": "string"
    }
  ]
}

Errors

HTTPMeaning
400use_api_key — a capability token was presented where an account credential is required.
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/identities" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/identities#

Create a mailbox

Credentials: apiKey, memberToken (optional)

With an API key or member token: created under that account, no proof-of-work, optionally under a handle the account is authorised for. Anonymous (no bearer): proof-of-work and the per-IP mint budget apply, handle is ignored, and the mailbox is ephemeral. A capability token cannot create mailboxes (400 use_api_key).

Request body

application/json

{
  "pow_challenge": "string",
  "pow_solution": "string",
  "label": "string",
  "handle": "string"
}

Responses

201 Mailbox created.

{
  "address": "string",
  "handle": "string",
  "capability_token": "string"
}

Errors

HTTPMeaning
400use_api_key, pow_required, invalid_handle
401unauthorized — missing, unknown, revoked or invalid credential.
403account_required, identity_quota, namespace_not_yours, namespace_quota, identity_not_proved, address_not_proved, name_reserved, parent_not_yours, already_named
409handle_taken
429mint_rate_limited (with Retry-After), mint_lifetime_cap, mint_source_halted.
500store_error (or another server-side code such as vault_error).
503open_namespace_closed — open namespace has no reserved-name list configured.

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/identities" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"pow_challenge": "string", "pow_solution": "string", "label": "string", "handle": "string"}'

DELETE /v1/identities#

Delete a mailbox and its messages

Credentials: apiKey, capToken, memberToken

An account credential may delete any mailbox it owns; a capability token may delete only its own mailbox.

Parameters

NameInTypeRequiredDescription
identityquerystringyesThe /k/… address to delete.

Responses

200 Deleted.

{
  "deleted": true
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403forbidden — capability token naming another mailbox.
404not_found
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X DELETE "https://postbox.pigeonpost.dev/v1/identities" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/identities/handle#

Give an existing mailbox a handle

Credentials: apiKey, memberToken

Request body

application/json

{
  "address": "string",
  "handle": "string",
  "capability_token": "string"
}

Responses

200 Bound.

{
  "address": "string",
  "handle": "string"
}

Errors

HTTPMeaning
400invalid_handle
401unauthorized — missing, unknown, revoked or invalid credential.
403account_required, not_your_mailbox, proof_required, namespace_quota, namespace_not_yours, identity_not_proved, address_not_proved, name_reserved, parent_not_yours, already_named
404unknown_mailbox
409already_named, handle_taken
500store_error (or another server-side code such as vault_error).
503open_namespace_closed

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/identities/handle" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"address": "string", "handle": "string", "capability_token": "string"}'

GET /v1/whoami#

The mailbox this credential acts as

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 Acting mailbox.

{
  "address": "string",
  "handle": "string"
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/whoami" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

GET /v1/workspace#

Fetch the acting mailbox's encrypted workspace context

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 Opaque ciphertext; the postbox holds no key for it.

{
  "nonce": "string",
  "ciphertext": "string",
  "kdf_salt": "string",
  "updated_at": 0
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404not_found
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/workspace" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

PUT /v1/workspace#

Store the acting mailbox's encrypted workspace context

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "nonce": "string",
  "ciphertext": "string",
  "kdf_salt": "string",
  "identity": "string"
}

Responses

200 Stored.

{
  "ok": true
}

Errors

HTTPMeaning
400invalid_workspace, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X PUT "https://postbox.pigeonpost.dev/v1/workspace" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nonce": "string", "ciphertext": "string", "kdf_salt": "string", "identity": "string"}'
