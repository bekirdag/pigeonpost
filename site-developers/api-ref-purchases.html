App Store, Google Play and tester handle entitlements.

MethodPathDoes
GET/v1/claims/testComplimentary tester handle offer and current holding
POST/v1/claims/testClaim a complimentary namespace (approved testers only)
GET/v1/claims/appleApp Store catalog and what this account already holds
POST/v1/claims/appleTurn a verified App Store purchase into a namespace or plan
GET/v1/claims/googleGoogle Play catalog and this account's subscriptions
POST/v1/claims/googleRedeem a Google Play purchase token (optionally naming the handle)
POST/v1/claims/google/assignAssign a name to an active, unnamed Google Play subscription

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/claims/test#

Complimentary tester handle offer and current holding

Credentials: memberToken

Responses

200 Offer.

{
  "eligible": false,
  "namespace": "string",
  "source": "string",
  "expires_at": 0,
  "mailbox": "string"
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/claims/test" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/claims/test#

Claim a complimentary namespace (approved testers only)

Credentials: memberToken

Request body

application/json

{
  "namespace": "string"
}

Responses

200 Claimed (idempotent for the same name).

{
  "eligible": false,
  "namespace": "string",
  "source": "string",
  "expires_at": 0,
  "mailbox": "string"
}

Errors

HTTPMeaning
400invalid_namespace
401unauthorized — missing, unknown, revoked or invalid credential.
403tester_required
409name_reserved, tester_already_named, namespace_taken
500reserved_names_unavailable, store_error

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/claims/test" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"namespace": "string"}'

App Store catalog and what this account already holds

Responses

  "product_ids": [
    "string"

  "plan": null,
  "max_handles": 0,

  "app_account_token": "string",
  "namespace": "string",
  "expires_at": 0,
  "handles": [
    {
      "original_transaction_id": "string",
      "namespace": "string",
      "product_id": "string",
      "environment": "string",
      "expires_at": 0,
      "active": false
    }
  ]
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
404not_found
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/claims/apple" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/claims/apple#

Turn a verified App Store purchase into a namespace or plan

Credentials: memberToken

404 not_found when App Store verification is not configured. The transaction is verified with Apple; nothing in the body is trusted.

Request body

application/json

{
  "transaction_id": "string",
  "namespace": "string"
}

Responses

200 Claimed. Single-handle products return {namespace, mailbox, expires_at, environment}; plan products return {plan, namespace, mailbox}. 

{
  "namespace": "string",
  "mailbox": "string",
  "expires_at": 0,
  "environment": "string",
  "plan": null
}

Errors

HTTPMeaning
400member_token_required, purchase_unknown, purchase_not_ours, purchase_account_required, name_required, invalid_namespace
401unauthorized — missing, unknown, revoked or invalid credential.
402purchase_expired, purchase_refunded
404not_found
409purchase_already_used, purchase_already_named, namespace_taken, name_reserved, handle_limit_reached, handle_already_subscribed, plan_capacity_reached
500appstore_unavailable, reserved_names_unavailable, store_error

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/claims/apple" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"transaction_id": "string", "namespace": "string"}'

}

  "mailbox": "string"
}

HTTPMeaning

500store_error (or another server-side code such as vault_error).

  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"purchase_token": "string", "namespace": "string"}'
