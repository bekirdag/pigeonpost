Accounts, API keys and account deletion.

MethodPathDoes
GET/v1/pow/challengeIssue a proof-of-work challenge
POST/v1/accountsCreate an account (proof-of-work gated)
GET/v1/account/deletion-requestStatus of this account's deletion request

GET/v1/api-keysList the account's API keys (never the secret)

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/pow/challenge#

Issue a proof-of-work challenge

Credentials: none

Required for anonymous POST /v1/identities and for POST /v1/accounts.

Responses

200 A challenge to solve.

{
  "challenge": "string",
  "bits": 0,
  "expires_at": 0
}

Example

curl -sS "https://postbox.pigeonpost.dev/v1/pow/challenge"

POST /v1/accounts#

Create an account (proof-of-work gated)

Credentials: none

Returns the account's first API key, shown once. Subject to the same per-IP mint budget as anonymous inboxes.

Request body

application/json

{
  "pow_challenge": "string",
  "pow_solution": "string"
}

Responses

201 Account created.

{
  "account_id": "string",
  "api_key": "string"
}

Errors

HTTPMeaning
400pow_required — missing, wrong or expired proof-of-work.
429mint_rate_limited (with Retry-After), mint_lifetime_cap, mint_source_halted.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/accounts" \
  -H "Content-Type: application/json" \
  -d '{"pow_challenge": "string", "pow_solution": "string"}'

GET /v1/account/deletion-request#

Status of this account's deletion request

Credentials: memberToken

Responses

200 Current request (null if none). Cache-Control - no-store.

{
  "request": {
    "request_id": "string",
    "requested_at": 0,
    "complete_by": 0,
    "completed_at": 0
  },
  "account": {
    "label": "string"
  }
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/account/deletion-request" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/account/deletion-request#

Request deletion of this account and its data

Credentials: memberToken

Idempotent; retries return the original receipt and cannot postpone its deadline.

Request body

application/json

{
  "confirm": false
}

Responses

200 Deletion request receipt.

{
  "request": {
    "request_id": "string",
    "requested_at": 0,
    "complete_by": 0,
    "completed_at": 0
  }
}

Errors

HTTPMeaning
400confirmation_required
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/account/deletion-request" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"confirm": false}'

GET /v1/api-keys#

List the account's API keys (never the secret)

Credentials: apiKey, memberToken

Responses

200 Keys.

{
  "keys": [
    {
      "id": "string",
      "prefix": "string",
      "created_at": 0
    }
  ]
}

Errors

HTTPMeaning
400use_api_key — a capability token was presented where an account credential is required.
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/api-keys" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/api-keys#

Issue a new account API key

Credentials: apiKey, memberToken

Responses

201 Key created; plaintext shown once.

{
  "api_key": "string"
}

Errors

HTTPMeaning
400use_api_key — a capability token was presented where an account credential is required.
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/api-keys" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

DELETE /v1/api-keys/{id}#

Revoke one of the account's API keys

Credentials: apiKey, memberToken

Parameters

NameInTypeRequiredDescription
idpathstringyes

Responses

200 Revoked.

{
  "revoked": true
}

Errors

HTTPMeaning
400use_api_key — a capability token was presented where an account credential is required.
401unauthorized — missing, unknown, revoked or invalid credential.
404not_found
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X DELETE "https://postbox.pigeonpost.dev/v1/api-keys/$ID" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"
