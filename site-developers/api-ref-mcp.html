POST /mcp#

MCP over Streamable HTTP (JSON-RPC 2.0)

Credentials: apiKey, capToken, memberToken (optional)

Methods: initialize, tools/list, ping, tools/call. The bearer token is optional for initialize/tools/list; tool calls authenticate with a capability token, an account API key or a member token. Tool failures (including authentication failures) are reported as error tool-results inside a 200 JSON-RPC response, not as HTTP errors. A notification (no id) gets an empty 202.

Request body

application/json

{
  "jsonrpc": "2.0",
  "id": "string",
  "method": "initialize",
  "params": {}
}

Responses

200 JSON-RPC response.

{
  "jsonrpc": "2.0",
  "id": null,
  "result": null,
  "error": {
    "code": 0,
    "message": "string"
  }
}

202 Notification accepted; no body.

Errors

HTTPMeaning
400Body was not JSON (invalid_request).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/mcp" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": "string", "method": "initialize", "params": {}}'

POST /chatgpt#

Account-linked MCP surface for ChatGPT

Credentials: memberToken (optional)

JSON-RPC 2.0 MCP endpoint exposing a restricted tool set. Tool calls require an OAuth access token whose audience is this resource and that carries the pigeonpost:read or pigeonpost:write scope. Requests from browser origins other than ChatGPT/OpenAI are refused with 403. Unsupported MCP-Protocol-Version header values get 400. Missing or invalid tokens get 401 (insufficient scope 403) with a JSON-RPC body carrying an mcp/www_authenticate challenge. Body limit 128 KiB.

Parameters

NameInTypeRequiredDescription
MCP-Protocol-VersionheaderstringOne of 2025-03-26, 2025-06-18, 2025-11-25.

Request body

application/json

{
  "jsonrpc": "2.0",
  "id": "string",
  "method": "initialize",
  "params": {}
}

Responses

200 JSON-RPC response.

{
  "jsonrpc": "2.0",
  "id": null,
  "result": null,
  "error": {
    "code": 0,
    "message": "string"
  }
}

202 Notification accepted; no body.

Errors

HTTPMeaning
400Unsupported MCP protocol version.
401Authorization required; JSON-RPC body with a WWW-Authenticate-style challenge in _meta.
403Origin not allowed, or token lacks the required scope.

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/chatgpt" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": "string", "method": "initialize", "params": {}}'
