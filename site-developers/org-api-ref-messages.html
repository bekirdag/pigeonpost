Base URL https://postbox.pigeonpost.dev/org/v1. Conventions, scopes and limits: Enterprise API overview.

POST /messages#

Send a direct message

Scope: messages:send

Sends a direct message as the key's send_as org agent mailbox to a member or agent mailbox of the same org. It takes the normal hosted direct path: the recipient's blocks, org rules, inbox policy, filters and quotas all apply. Rooms are end-to-end encrypted and cannot be posted to with a key (409 room_encrypted); see the guide "Post build results into a room".

Parameters

NameInTypeRequiredDescription
Idempotency-Keyheaderstring1-255 printable ASCII characters. Scoped to the key and route; a replay within 24 h returns the recorded response with Idempotent-Replayed: true. Reusing it for a different request is 409 idempotency_conflict.

Request body

application/json

{
  "to": "/acme/john",
  "body": "Your laptop is ready for pickup at the front desk.",
  "thread_title": "Onboarding"
}

Responses

201 Created.

{
  "data": {
    "message_id": "msg_irlvz5nsqujnovsex5kkkf6454",
    "to": "/acme/john",
    "from": "/acme/ci-bot",
    "sent_at": "2026-10-27T10:15:00Z",
    "msg_ref": "mref_qbhxi4e4mkdmbwjdixfcpq5mob"
  }
}

Errors

HTTPCodeWhen
400bad_requestThe body or a parameter is malformed: not JSON, a wrong type, an unknown enum value, or a field out of range. The message names the field.
401unauthorizedNo key, an unknown key, a revoked key or an expired key. One answer for all four, so a caller cannot probe which.
403ip_not_allowedThe request came from an address outside the key's IP allowlist.
403insufficient_scopeThe key does not hold the scope this route needs. The route's scope is listed in the reference.
403forbiddenThe person who created the key no longer has the authority for this action (demoted or removed), or the target is out of a key's reach: the owner, or a member holding an admin role.
403recipient_not_in_orgPOST /messages: the recipient is not a live mailbox of this org. API messages only go to the org's own members and agents.
403not_admittedPOST /messages: the recipient's blocks, org rules or inbox policy do not admit messages from the key's send_as mailbox.
404feature_disabledThe Enterprise API is not enabled for this org (org_api feature flag).
409room_encryptedPOST /messages targeted a room or group. Rooms are end-to-end encrypted; post with an enrolled agent instead.
409org_inactiveThe org is not live (pending, unprovisioned or suspended).
409org_read_onlyThe org is read-only after a lapsed payment: reads work, writes do not.
409idempotency_conflictThis Idempotency-Key was already used on this route with a different request (method, path or body).
413payload_too_largeThe message body is over 64 KB.
429rate_limitedOver the key's rate limit (600 requests a minute, of which 60 writes). Wait for Retry-After seconds.
500store_errorThe server could not complete the request. Safe to retry with the same Idempotency-Key.
404recipient_unresolvedNo mailbox answers at to.
400invalid_recipientto is not a Pigeonpost address or handle.
409send_as_unavailableThe agent this key sends as is not an active agent of the organization.
409recipient_inbox_fullThe recipient's mailbox is over its storage quota.
429stranger_rate_limitedThe recipient is receiving too many messages from senders it does not know; retry later.

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/org/v1/messages" \
  -H "Authorization: Bearer $PIGEONPOST_ORG_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"to": "/acme/john", "body": "Your laptop is ready for pickup at the front desk.", "thread_title": "Onboarding"}'
