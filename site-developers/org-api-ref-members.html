Invite, rename, suspend, reactivate and remove ordinary members.

MethodPathDoes
GET/membersList members
POST/membersInvite a member
GET/members/{member}Get a member
PATCH/members/{member}Rename a member
DELETE/members/{member}Remove a member
POST/members/{member}/suspendSuspend a member
POST/members/{member}/reactivateReactivate a member
POST/members/{member}/resend-inviteResend an invitation

Base URL https://postbox.pigeonpost.dev/org/v1. Conventions, scopes and limits: Enterprise API overview.

GET /members#

List members

Scope: org:read

Every member of the org, invited, active and suspended. Filter with status.

Parameters

NameInTypeRequiredDescription
statusquerystringOnly members in this state. One of invited, active, suspended.
limitqueryintegerPage size, 1..200 (default 50).
cursorquerystringOpaque next_cursor from the previous page. Pass back exactly.

200 Success.

POST /members#

Invite a member

Scope: members:write

Invites one ordinary member (no roles; role grants stay on the dashboard). The invitation link in the response is single-use and returned only here (Cache-Control: no-store); with delivery: copy_link deliver it yourself. Seats, verified domains and handle rules apply as in the dashboard.

Parameters

NameInTypeRequiredDescription
Idempotency-Keyheaderstring1-255 printable ASCII characters. Scoped to the key and route; a replay within 24 h returns the recorded response with Idempotent-Replayed: true. Reusing it for a different request is 409 idempotency_conflict.

Request body

application/json

{
  "first_name": "Jane",
  "last_name": "Doe",
  "contact": "jane.doe@example.com",
  "handle": "jane"
}

Responses

201 Created.

{
  "data": {
    "member": {
      "id": "mem_qh4pnxpiqns7heuhs3whvjj7ok",
      "handle": "/acme/jane",
      "address": null,
      "first_name": "Jane",
      "last_name": "Doe",
      "status": "invited",
      "roles": [],
      "contact_masked": "j***@example.com",
      "invited_at": "2026-10-27T10:15:00Z",
      "joined_at": null,
      "last_active_at": null
    },
    "invitation": {
      "id": "inv_s3mwglzwgvsmymbskikattzcvb",
      "link": "https://enterprise.pigeonpost.dev/invite#EXAMPLE-invitation-token",
      "expires_at": "2026-11-03T10:15:00Z",
      "delivery": "queued"
    }
  }
}

Errors

HTTPCodeWhen
400invalid_handleA handle is not valid for this org: wrong namespace, bad characters, reserved, or too long. Org handles look like /acme/john; on input the bare name john is accepted too.
400invalid_contactThe invitation contact address is not a valid address.
400bad_requestThe body or a parameter is malformed: not JSON, a wrong type, an unknown enum value, or a field out of range. The message names the field.
401unauthorizedNo key, an unknown key, a revoked key or an expired key. One answer for all four, so a caller cannot probe which.
403ip_not_allowedThe request came from an address outside the key's IP allowlist.
403insufficient_scopeThe key does not hold the scope this route needs. The route's scope is listed in the reference.
403forbiddenThe person who created the key no longer has the authority for this action (demoted or removed), or the target is out of a key's reach: the owner, or a member holding an admin role.
404feature_disabledThe Enterprise API is not enabled for this org (org_api feature flag).
409seat_limitEvery seat is in use (owner, active, suspended and invited members all count). Buy seats or remove someone first.
409handle_takenThe handle already belongs to a member, an agent, or is held for a successor.
409already_invitedThis contact address already has a live invitation or membership in the org.
409domain_not_verifiedThe org only invites addresses on its verified domains (invite_domains_only), and this one is not.
409org_inactiveThe org is not live (pending, unprovisioned or suspended).
409org_read_onlyThe org is read-only after a lapsed payment: reads work, writes do not.
409idempotency_conflictThis Idempotency-Key was already used on this route with a different request (method, path or body).
429rate_limitedOver the key's rate limit (600 requests a minute, of which 60 writes). Wait for Retry-After seconds.
500store_errorThe server could not complete the request. Safe to retry with the same Idempotency-Key.

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/org/v1/members" \
  -H "Authorization: Bearer $PIGEONPOST_ORG_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"first_name": "Jane", "last_name": "Doe", "contact": "jane.doe@example.com", "handle": "jane"}'

DELETE /members/{member}#

Remove a member

Scope: members:write

Offboards the member: memberships, roles, delegations, rooms and device credentials they approved are revoked. With mode=reserve (default) the address is held for a successor (invite someone to the same handle); the old mailbox keeps its history, detached from the org. mode=delete releases the address.

Parameters

NameInTypeRequiredDescription
memberpathstringyesMember id (mem_…) or the member's name inside the org (john for /acme/john).
modequerystringreserve (default) or delete. One of reserve, delete.
Idempotency-Keyheaderstring1-255 printable ASCII characters. Scoped to the key and route; a replay within 24 h returns the recorded response with Idempotent-Replayed: true. Reusing it for a different request is 409 idempotency_conflict.

Responses

200 Success.

{
  "data": {
    "id": "mem_s3mwglzwgvsmymbskikattzcvb",
    "removed": true,
    "mode": "reserve"
  }
}
