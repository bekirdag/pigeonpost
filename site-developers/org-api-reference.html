Enterprise API reference

Every endpoint of the Enterprise API (https://postbox.pigeonpost.dev/org/v1), generated from openapi/pigeonpost-org.v1.yaml. Read the overview first for keys, scopes, pagination, idempotency and rate limits; every error code is in the error reference.

Downloads: OpenAPI (JSON), Postman collection, Bruno collection. Both collections use the variables {{baseUrl}} and {{token}}; set token to your pk_org_… key.

Key#

The calling key itself.

MethodPathDoes
GET/keyDescribe this key
DELETE/keyRevoke this key

Organization#

The org: plan, limits, settings.

MethodPathDoes
GET/orgGet the organization

Members#

Invite, rename, suspend, reactivate and remove ordinary members.

MethodPathDoes
GET/membersList members
POST/membersInvite a member
GET/members/{member}Get a member
PATCH/members/{member}Rename a member
DELETE/members/{member}Remove a member
POST/members/{member}/suspendSuspend a member
POST/members/{member}/reactivateReactivate a member
POST/members/{member}/resend-inviteResend an invitation

Roles#

Role definitions and holders (read only).

MethodPathDoes
GET/rolesList roles

Agents#

Org agent mailboxes, their delegations and enrollment codes.

MethodPathDoes
GET/agentsList agents
POST/agentsCreate an agent
GET/agents/{agent}Get an agent
DELETE/agents/{agent}Delete an agent
POST/agents/{agent}/disconnectDisconnect an agent
GET/agents/{agent}/delegationsList an agent's delegations
GET/agents/{agent}/enrollmentsList an agent's enrollment codes
DELETE/agents/{agent}/enrollments/{enrollment}Revoke an enrollment code

Rules#

Org trust rules. Keys may only add restrictions.

MethodPathDoes
GET/rulesList rules
POST/rulesCreate a restrictive rule
PATCH/rules/{rule}Update a rule
DELETE/rules/{rule}Delete a rule
POST/rules/evaluateEvaluate rules (dry run)

Rooms#

End-to-end-encrypted org rooms (metadata and invitations only).

MethodPathDoes
GET/roomsList rooms
POST/roomsCreate a room
PATCH/rooms/{room}Update a room
DELETE/rooms/{room}Delete a room
POST/rooms/{room}/membersInvite a mailbox to a room

Audit#

The org audit log, for SIEM streaming.

MethodPathDoes
GET/auditRead the audit log

Usage and billing#

Seats, agents, storage, calls and plan status.

MethodPathDoes
GET/usageGet usage
GET/billingGet billing status

Webhooks#

Signed event deliveries to your HTTPS endpoint.

MethodPathDoes
GET/webhooksList webhooks
POST/webhooksCreate a webhook
DELETE/webhooks/{webhook}Delete a webhook
POST/webhooks/{webhook}/rotateRotate a webhook secret
GET/webhooks/{webhook}/deliveriesList delivery attempts

Messages#

Direct messages from the key's agent mailbox to org mailboxes.

MethodPathDoes
POST/messagesSend a direct message
