POST /v1/report-spam#

Report the sender of a received message, or the caller of an incoming call, as spam

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "message_id": "string",
  "call_id": "string",
  "identity": "string"
}

Responses

200 Report recorded (or already recorded).

{
  "reported": false,
  "sender": "string",
  "reports_against_sender": 0,
  "detail": "string"
}

Errors

HTTPMeaning
400invalid_report, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403reporter_not_in_good_standing, wrong_identity, not_in_account
404not_found
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/report-spam" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message_id": "string", "call_id": "string", "identity": "string"}'

GET /v1/contacts#

The acting mailbox's contacts, stranger policy and verb vocabulary

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.
admissionquerystringblock lists only blocks (exact addresses, handles and /ns/* wildcards). One of allow, block.

Responses

200 Contacts.

{
  "contacts": [
    {
      "peer": "string",
      "alias": "string",
      "admission": "allow",
      "autonomy": "review",
      "allowed_verbs": [
        "string"
      ],
      "created_at": 0,
      "updated_at": 0
    }
  ],
  "policy": {
    "read_receipts": false,
    "accept_all": false,
    "auto_accept_known": false,
    "unknown_calls": "ring",
    "unnamed_calls": "ring",
    "unnamed_messages": "show",
    "unknown_messages": "show",
    "low_reputation": "filter",
    "group_members_known": false,
    "call_history_days": 0
  },
  "vocabulary": {
    "grantable": [
      "string"
    ],
    "never_auto": [
      "string"
    ],
    "needs_machine_opt_in": [
      "string"
    ]
  }
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/contacts" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

PUT /v1/contacts#

Add or amend a contact (human path; may raise trust)

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "peer": "string",
  "alias": "string",
  "admission": "allow",
  "autonomy": "review",
  "allowed_verbs": [
    "string"
  ],
  "identity": "string"
}

Responses

200 The stored contact.

{
  "peer": "string",
  "alias": "string",
  "admission": "allow",
  "autonomy": "review",
  "allowed_verbs": [
    "string"
  ],
  "created_at": 0,
  "updated_at": 0
}

Errors

HTTPMeaning
400invalid_peer, invalid_verb, an invalid enum value, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X PUT "https://postbox.pigeonpost.dev/v1/contacts" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"peer": "string", "alias": "string", "admission": "allow", "autonomy": "review", "allowed_verbs": ["string"], "identity": "string"}'

PUT /v1/policy#

Set the acting mailbox's stranger defaults and filtering settings

Credentials: apiKey, capToken, memberToken

Any subset of fields. All values are validated before anything is written (invalid_policy). Agents (MCP) may only make settings stricter. Returns the whole policy.

Request body

application/json

{
  "read_receipts": false,
  "accept_all": false,
  "auto_accept_known": false,
  "unknown_calls": "ring",
  "unnamed_calls": "ring",
  "unnamed_messages": "show",
  "unknown_messages": "show",
  "low_reputation": "filter",
  "group_members_known": false,
  "call_history_days": 0,
  "identity": "string"
}

Responses

200 The resulting policy.

{
  "read_receipts": false,
  "accept_all": false,
  "auto_accept_known": false,
  "unknown_calls": "ring",
  "unnamed_calls": "ring",
  "unnamed_messages": "show",
  "unknown_messages": "show",
  "low_reputation": "filter",
  "group_members_known": false,
  "call_history_days": 0
}

Errors

HTTPMeaning
400no_identity (account has no mailboxes) or identity_required (account has several; pass identity).
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X PUT "https://postbox.pigeonpost.dev/v1/policy" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \

POST /v1/filtered/accept#

Accept a sender out of Filtered (feature message_filtering)

Credentials: apiKey, capToken, memberToken

Adds the sender as a contact with admission=allow (by handle when it has one) and moves all of its filtered messages into the inbox. Not available through a connector.

Request body

application/json

{
  "peer": "string",
  "identity": "string"
}

Responses

200 Accepted.

{
  "accepted": false,
  "contact": {
    "peer": "string",
    "alias": "string",
    "admission": "allow",
    "autonomy": "review",
    "allowed_verbs": [
      "string"
    ],
    "created_at": 0,
    "updated_at": 0
  },
  "moved": 0
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
404not_found

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/filtered/accept" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"peer": "string", "identity": "string"}'
