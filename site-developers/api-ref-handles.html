POST /v1/github/device#

Start a GitHub device login to prove a GitHub username

Credentials: apiKey, memberToken

Responses

200 What the person enters at GitHub.

{
  "device_code": "string",
  "user_code": "string",
  "verification_uri": "string",
  "expires_in": 0,
  "interval": 0
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403account_required — a capability token was presented where an account credential is required.
404github_login_unavailable
502github_unreachable
503github_device_flow_disabled

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/github/device" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/github/claim#

Finish a GitHub device login and record the username for this account

Credentials: apiKey, memberToken

Polled; pending and slow_down are ordinary 200 answers.

Request body

application/json

{
  "device_code": "string"
}

Responses

200 Status.

{
  "status": "pending",
  "login": "string",
  "handle": "/github/alex"
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403account_required — a capability token was presented where an account credential is required.
404github_login_unavailable
409login_changed_hands, login_already_claimed
500store_error (or another server-side code such as vault_error).
502github_refused

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/github/claim" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"device_code": "string"}'

GET /v1/handles/{name}/availability#

Is this namespace free to buy?

Credentials: apiKey, memberToken (optional)

Public. When called with the account credential of a lapsed namespace's owner, may answer available - true, reason - renewal (then Cache-Control - private, no-store).

Parameters

NameInTypeRequiredDescription
namepathstringyes

Responses

200 Availability.

{
  "name": "string",
  "available": false,
  "reason": "invalid"
}

Errors

HTTPMeaning
500reserved_names_unavailable, store_error

Example

curl -sS "https://postbox.pigeonpost.dev/v1/handles/$NAME/availability" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

GET /v1/me/handles#

Every namespace the signed-in account holds

Credentials: memberToken

Parameters

NameInTypeRequiredDescription
include_inactivequeryboolean

Responses

200 Holdings (Cache-Control - private, no-store).

{
  "account": "string",
  "handles": [
    {
      "namespace": "string",
      "source": "string",
      "verified_at": 0,
      "expires_at": 0,
      "active": false
    }
  ]
}

Errors

HTTPMeaning
400member_token_required — this route needs a member sign-in, not a key or capability token.
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS "https://postbox.pigeonpost.dev/v1/me/handles" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

HTTPMeaning

403address_not_verified
409address_held, address_moved
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/claims/address" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"

POST /v1/claims/plan#

Register a name within the account's Pigeonpost Cloud web plan

Credentials: memberToken

Request body

application/json

{
  "namespace": "string"
}

Responses

200 The name is registered (idempotent).

{
  "namespace": "string",
  "mailbox": "string",
  "capacity": 0,
  "used": 0
}

Errors

HTTPMeaning
400invalid_namespace, member_token_required, bad_request
401unauthorized — missing, unknown, revoked or invalid credential.
402no_plan
403human_required
409plan_capacity_reached, name_reserved, namespace_taken, handle_already_subscribed

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/claims/plan" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"namespace": "string"}'
