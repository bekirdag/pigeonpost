POST /v1/shell/sessions#

Request an SSH session to an agent's workspace (SDS §11.6)

Credentials: memberToken

A person with a recent strong sign-in (step_up_required otherwise) who owns the agent, is its org's owner, or holds a live ssh delegation for it; the org must allow SSH and the agent admin must have enabled it; the agent's machine must be connected with SSH enabled. API keys, org keys, connectors and agents get human_required. 201 returns the credentials; 202 when the org requires approval.

Request body

application/json

{
  "agent": "string",
  "client_public_key": "string",
  "cols": 0,
  "rows": 0
}

Responses

201 {session_id, state: issued, broker_url, leg_token, host_key, host_key_fp, user_cert, ssh_user, principal, ca_fp, connect_by, idle_secs, ends_by, session}

{}

202 {session_id, state: awaiting_approval, session} — waiting for a supervisor's approval
