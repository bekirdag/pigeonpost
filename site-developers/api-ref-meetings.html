Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

GET /v1/meetings#

Meetings whose notes the caller agreed to, newest first (feature meeting_summaries)

Credentials: apiKey, memberToken

Only meetings where this account consented to notes and has not removed its copy, before the retention date. Briefs are ciphertext; see docs/meeting-summaries.md.

Responses

200 The list.

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403credential_not_accepted (a mailbox token or connector)

GET /v1/meetings/{id}#

One meeting's status and, when ready, its encrypted brief with the caller's own key wraps

Credentials: apiKey, memberToken

Absent, expired, removed, declined and never-attended meetings all answer 404 not_found. The brief (summary, decisions, action items, open questions and transcript) is AES-256-GCM ciphertext; each keys entry wraps the content key for one of the caller's notes keys (ECDH P-256 + HKDF-SHA256 + AES-256-GCM, docs/meeting-summaries.md).

Parameters

NameInTypeRequiredDescription
idpathstringyes

Responses

200 Status, plus ciphertext when state is ready.

Errors

403credential_not_accepted
404not_found
