Rooms

AllKeyOrganizationMembersRolesAgentsRulesRoomsAuditUsage and billingWebhooksMessages

End-to-end-encrypted org rooms (metadata and invitations only).

MethodPathDoes
GET/roomsList rooms
POST/roomsCreate a room
PATCH/rooms/{room}Update a room
DELETE/rooms/{room}Delete a room
POST/rooms/{room}/membersInvite a mailbox to a room

Base URL https://postbox.pigeonpost.dev/org/v1. Conventions, scopes and limits: Enterprise API overview.

GET /rooms#

List rooms

Scope: org:read

Every org room. Metadata only; rooms are end-to-end encrypted.

Parameters

NameInTypeRequiredDescription
limitqueryintegerPage size, 1..200 (default 50).
cursorquerystringOpaque next_cursor from the previous page. Pass back exactly.

Responses

200 Success.

{
  "data": [
    {
      "id": "grp_qrmudhkm7zvrvswbjgkbbkwp7l",
      "name": "builds",
      "description": "CI results for the web app",
      "join_policy": "private",
      "post_policy": "everyone",
      "listed": true,
      "auto_join": false,
      "activation_state": "active",
      "member_count": 6,
      "created_by": "/acme/ci-bot"
    }
  ],
  "next_cursor": "eyJhZnRlciI6IjIwMjYtMTAtMjcifQ"
}

Errors

HTTPCodeWhen
400invalid_cursorThe cursor was not produced by this list, or was altered. Pass back next_cursor exactly as received.
401unauthorizedNo key, an unknown key, a revoked key or an expired key. One answer for all four, so a caller cannot probe which.
403ip_not_allowedThe request came from an address outside the key's IP allowlist.
403insufficient_scopeThe key does not hold the scope this route needs. The route's scope is listed in the reference.
403forbiddenThe person who created the key no longer has the authority for this action (demoted or removed), or the target is out of a key's reach: the owner, or a member holding an admin role.
404feature_disabledThe Enterprise API is not enabled for this org (org_api feature flag).
409org_inactiveThe org is not live (pending, unprovisioned or suspended).
429rate_limitedOver the key's rate limit (600 requests a minute, of which 60 writes). Wait for Retry-After seconds.
500store_errorThe server could not complete the request. Safe to retry with the same Idempotency-Key.

Example

curl -sS "https://postbox.pigeonpost.dev/org/v1/rooms" \
  -H "Authorization: Bearer $PIGEONPOST_ORG_KEY"

POST /rooms#

Create a room

Scope: rooms:write

Creates a room owned by owner, an active org member or agent mailbox. The room is provisioning until the owner's device activates its encryption (their app does this the next time it syncs).

Parameters

NameInTypeRequiredDescription
Idempotency-Keyheaderstring1-255 printable ASCII characters. Scoped to the key and route; a replay within 24 h returns the recorded response with Idempotent-Replayed: true. Reusing it for a different request is 409 idempotency_conflict.

Request body

application/json

{
  "name": "builds",
  "owner": "/acme/ci-bot",
  "description": "CI results for the web app",
  "listed": true
}

Responses

201 Created.

{
  "data": {
    "id": "grp_qrmudhkm7zvrvswbjgkbbkwp7l",
    "name": "builds",
    "description": "CI results for the web app",
    "join_policy": "private",
    "post_policy": "everyone",
    "listed": true,
    "auto_join": false,
    "activation_state": "provisioning",
    "member_count": 1,
    "created_by": "/acme/ci-bot"
  }
}

Errors

HTTPCodeWhen
400invalid_handleA handle is not valid for this org: wrong namespace, bad characters, reserved, or too long. Org handles look like /acme/john; on input the bare name john is accepted too.
400bad_requestThe body or a parameter is malformed: not JSON, a wrong type, an unknown enum value, or a field out of range. The message names the field.
401unauthorizedNo key, an unknown key, a revoked key or an expired key. One answer for all four, so a caller cannot probe which.
403ip_not_allowedThe request came from an address outside the key's IP allowlist.
403insufficient_scopeThe key does not hold the scope this route needs. The route's scope is listed in the reference.
403forbiddenThe person who created the key no longer has the authority for this action (demoted or removed), or the target is out of a key's reach: the owner, or a member holding an admin role.
404not_foundNo such member, agent, rule, room, webhook or enrollment in this org.
404feature_disabledThe Enterprise API is not enabled for this org (org_api feature flag).
409org_inactiveThe org is not live (pending, unprovisioned or suspended).
409org_read_onlyThe org is read-only after a lapsed payment: reads work, writes do not.
409idempotency_conflictThis Idempotency-Key was already used on this route with a different request (method, path or body).
429rate_limitedOver the key's rate limit (600 requests a minute, of which 60 writes). Wait for Retry-After seconds.
500store_errorThe server could not complete the request. Safe to retry with the same Idempotency-Key.
400not_org_mailboxThe handle or address given is not an active member or agent mailbox of this organization.

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/org/v1/rooms" \
  -H "Authorization: Bearer $PIGEONPOST_ORG_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"name": "builds", "owner": "/acme/ci-bot", "description": "CI results for the web app", "listed": true}'

POST /rooms/{room}/members#

Invite a mailbox to a room

Scope: rooms:write

Sends a room invitation to a live org mailbox. The person (or agent) accepts it in their app; a room member's device then adds them to the encryption group. The API never adds anyone to the encryption group itself.

Parameters

NameInTypeRequiredDescription
roompathstringyesRoom id (grp_…).
Idempotency-Keyheaderstring1-255 printable ASCII characters. Scoped to the key and route; a replay within 24 h returns the recorded response with Idempotent-Replayed: true. Reusing it for a different request is 409 idempotency_conflict.

Request body

application/json

{
  "handle": "john"
}

Responses

200 Success.

{
  "data": {
    "room_id": "grp_qrmudhkm7zvrvswbjgkbbkwp7l",
    "handle": "/acme/john",
    "address": "/k/za21mg7q4nfepakf34acbz5ssw",
    "state": "invited"
  }
}
