Push notification registrations.

MethodPathDoes
POST/v1/devicesRegister a push token for the acting mailbox
DELETE/v1/devices/{token}Stop pushing to a device (scoped to the caller's account or mailbox)

Base URL https://postbox.pigeonpost.dev. Overview: HTTP API.

POST /v1/devices#

Register a push token for the acting mailbox

Credentials: apiKey, capToken, memberToken

Request body

application/json

{
  "token": "string",
  "platform": "apns",
  "environment": "production",
  "identity": "string",
  "kind": "alert",
  "os": "ios"
}

Responses

200 Registered.

{
  "ok": true
}

Errors

HTTPMeaning
400unknown_platform, unknown_kind, unknown_os, invalid_device_token, no_identity, identity_required
401unauthorized — missing, unknown, revoked or invalid credential.
403wrong_identity (capability token bound to another mailbox) or not_in_account.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X POST "https://postbox.pigeonpost.dev/v1/devices" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"token": "string", "platform": "apns", "environment": "production", "identity": "string", "kind": "alert", "os": "ios"}'

DELETE /v1/devices/{token}#

Stop pushing to a device (scoped to the caller's account or mailbox)

Credentials: apiKey, capToken, memberToken

Parameters

NameInTypeRequiredDescription
tokenpathstringyes

Responses

200 Done.

{
  "ok": true,
  "removed": null
}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
500store_error (or another server-side code such as vault_error).

Example

curl -sS -X DELETE "https://postbox.pigeonpost.dev/v1/devices/$TOKEN" \
  -H "Authorization: Bearer $PIGEONPOST_TOKEN"
