GET /v1/groups/{id}/streams#

The group's live stream, if any

Credentials: apiKey, capToken, memberToken

Active members. Requires the groups and streaming feature flags (docs/streaming.md).

Parameters

NameInTypeRequiredDescription
idpathstringyes
identityquerystringWhich of the account's mailboxes to act as. Needed when an account credential owns more than one; must match the mailbox when a capability token is used.

Responses

200 {streams:[stream]}

Errors

HTTPMeaning
401unauthorized — missing, unknown, revoked or invalid credential.
403A group refusal: {error, detail, message} with codes from docs/groups.md (not_member, not_admin, owner_only, posting_restricted, banned, group_full, invalid_link, invite_required, already_member, human_required, group_deleted, revision_conflict, epoch_conflict, key_activation_pending, idempotency_conflict, feature_disabled, …).
404A group refusal: {error, detail, message} with codes from docs/groups.md (not_member, not_admin, owner_only, posting_restricted, banned, group_full, invalid_link, invite_required, already_member, human_required, group_deleted, revision_conflict, epoch_conflict, key_activation_pending, idempotency_conflict, feature_disabled, …).
