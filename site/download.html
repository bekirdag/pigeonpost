Installation help · Release notes · Checksums

Install on your Mac

  1. Open the downloaded ZIP file.
  2. Drag Pigeonpost Desktop into your Applications folder.
  3. Open Pigeonpost Desktop and sign in.

macOS may ask you to confirm the first time you open an app downloaded from the internet. No changes to your Mac’s security settings are needed.

Install on Linux

Flatpak: open the downloaded bundle with your software installer, or run flatpak install --user ./Pigeonpost-Desktop-1.0.2-x86_64.flatpak from its folder. For ARM64, use the aarch64 filename instead. Set up Flatpak if it is not installed. The first installation also downloads the GNOME runtime.

Debian / Ubuntu: open a terminal in the download folder and run sudo apt install ./pigeonpost-desktop_1.0.2_all.deb. This installs the app and its native dependencies.

Launch Pigeonpost from your applications menu, then sign in through your browser. Your desktop keyring remembers the account. Handle purchases open the Pigeonpost website.

Tested on Ubuntu 24.04 with x86_64 and ARM64 processors. Other desktops and distributions need the listed dependencies. These are direct release downloads; install a newer package from this page to update. The app is not yet listed on Flathub.
