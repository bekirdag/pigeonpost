Publish on Pigeonpost

For developers who want to sell apps that run in a Nest

A Nest app is code you publish and Pigeonpost runs for buyers in the Marketplace. Pigeonpost builds it from your source, reviews it, and runs a separate, isolated copy for each buyer. The full guide is in the developer docs.

1. Build with the dev kit

The dev kit is part of the Pigeonpost CLI. Start from a template, run it on your own machine against a mock model broker, and check it against the platform's rules:

pigeonpost nest init       # start an app from a template
pigeonpost nest run        # run it locally
pigeonpost nest validate   # check the package
pigeonpost nest submit     # ask Pigeonpost to build a pinned commit for review

2. Test on staging

Besides the local kit, you can try a release in hosted test Nests on our test environment, staging.pigeonpost.dev, before buyers see it.

3. Apply as a publisher

Sign in at partner.pigeonpost.dev and start your application. You can publish as yourself or for an organization you administer. Complete the saved application: legal and contact details, country-specific company registration and tax evidence (or individual identity verification through ShuftiPro), bank details and a public publisher profile. Pigeonpost staff review your application and may request more documents before approval. You can follow every decision in your publisher console. App releases require a separate security review.

4. Review and approval

Pigeonpost builds each release from your source tree, with no network access during the build. It is scanned, then behaviour-tested, and a named Pigeonpost staff member approves or rejects it. You see the findings in the publisher console. When a release is approved, you decide when its listing goes live. Every new version is reviewed again.

5. Earnings

You set a one-off or monthly price for each listing. Pigeonpost keeps a commission and pays publishers monthly, in Turkish lira, by bank transfer to a bank account in Türkiye. The commission and payout terms are shown when you apply.
